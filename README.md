# MS COLLECTION Billing App

First working Android version for a 58mm MPT-II Bluetooth ESC/POS thermal printer.

## Included
- Offline billing
- Customer name/mobile
- Add/remove items
- Quantity, rate and total
- Bill number
- Bluetooth paired-device selection
- MPT-II classic Bluetooth SPP printing
- 58mm ESC/POS receipt
- Test print
- No ads
- No subscription

## Printer setup
1. Turn on the MPT-II.
2. Open Android Bluetooth settings.
3. Pair with MPT-II (the exact PIN depends on the printer variant; common manuals list 0000).
4. Open the app and tap Connect.
5. Select MPT-II.
6. Tap Test Print.

## Build
Open this folder in Android Studio and build/install the app.
This source is intentionally free of advertising and subscription SDKs.
